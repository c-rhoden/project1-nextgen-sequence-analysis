# project1-nextgen-sequence-analysis
This project is a next generation sequence analysis aiming to characterise 3 samples of S. pombe yeast treated with a genotoxic agent compared with 3 wild type samples with the purpose of developing python functions to clean up DNA sequences and identify mutations. There was 6 samples (3 treated, 3 wild) with 1000 reads for each sample (n = 6000). To analyse these results first the reads were validated - to be a correct read the sequence had to be fully converted to upper case and and have no invalid characters (only contain A,C,T,G) and finally be the same length as the reference (200 nt). Once validated mutations needed to be located with a new function that iterates through the index of the read and the reference to find where the characters differ between the read and the reference. When mutations were located they were tabulated using an analyse function which could be used for summarising.
