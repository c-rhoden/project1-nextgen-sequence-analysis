# project1-nextgen-sequence-analysis
This project is a next generation sequence analysis aiming to characterise 3 samples of S. pombe yeast treated with a genotoxic agent compared with 3 wild type samples with the purpose of developing python functions to clean up DNA sequences and identify mutations. There was 6 samples (3 treated, 3 wild) with 1000 reads for each sample (n = 6000)
